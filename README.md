# Phishing URL Detector using Machine Learning

## Project Overview
This project is a cybersecurity-focused machine learning system that detects phishing websites. The model is trained on over 11,000 website samples and can classify whether a website is safe or phishing.

Phishing attacks are one of the most common cybersecurity threats. This project demonstrates how machine learning can be used to automatically detect malicious websites.

## Features
- Detects phishing and legitimate websites
- Uses Random Forest Machine Learning algorithm
- Achieves 96.78% accuracy
- Built using Python and scikit-learn
- Implemented in Google Colab

## Technologies Used
- Python
- scikit-learn
- pandas
- Google Colab
- Machine Learning

## Machine Learning Model
- Algorithm: Random Forest Classifier
- Dataset size: 11,055 websites
- Accuracy: 96.78%

## How it Works
1. Loads phishing website dataset
2. Splits data into training and testing sets
3. Trains machine learning model
4. Predicts whether a website is phishing or safe
